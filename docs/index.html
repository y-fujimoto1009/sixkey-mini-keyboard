キーを選んで設定を始められます。

初回のファーム更新・使い方
  1. 対応ファームをダウンロード。現在のゲームなどは、このキーボード用ファームへ置き換わります。
  2. RP2040-ZeroのBOOTボタンを押しながらUSBを接続し、表示されたRPI-RP2ドライブにUF2をコピーします。
  3. 再起動後、このページで「USBで接続」を押し、対応するシリアルポートを選びます。BOOT状態では設定できません。
  4. 割り当てを選んで「本体に保存」。保存後、USBを抜き差ししても設定が残るか確認してください。

初回は1〜6・音量上下・ミュートです。液晶には各キーの設定番号が表示されます。実機でのUSB書き込み・電源再投入後の保持は未検証です。書き込み中はUSBを抜かないでください。
