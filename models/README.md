# ケース設計用3Dモデル

## Tinkercadで使う

1. `keyboard-assembly-mm.stl`をダウンロードする。
2. Tinkercadの新しいデザインで「インポート」を開き、STLを選ぶ。
3. 単位はmm、倍率は100%にする。部品付きモデルの幅は約84 mmです。
4. モデルを基準にケースを作る。完成後はケースだけを選択してSTLをエクスポートする。

基板だけを使う場合は`pcb-only-mm.stl`、CADで扱う場合はSTEPを使います。`parts/`にはRP2040-Zero、LCD、EC11＋ノブ、MXスイッチ＋キーキャップの個別モデルを収録しています。

## 寸法・確認範囲

- 基板：84 × 73.05 × 1.6 mm。
- 部品付きSTLの外接寸法：約84 × 73.255 × 34.3 mm。
- STLは閉じたメッシュとして検証済み。Tinkercadへの実際の取り込みとケースの実物適合は未確認です。
- LCDの基板からの突出10.5 mm、RP2040-Zeroの裏面突出8.7 mm、EC11の軸・ノブ寸法、MXスイッチ・キーキャップ高さは仮寸法です。実物で確認してください。
- はんだの盛り、端子の突出、ネジ頭、USBケーブルのプラグ、キーの動作範囲を完全には再現していません。ケースにはこれらの余裕も確保してください。
- STEP内の長穴は小さい側の穴径の円で簡略化しています。基板STLは元のドリル形状を反映しています。

このモデルは配置とケース検討の参考モデルです。
