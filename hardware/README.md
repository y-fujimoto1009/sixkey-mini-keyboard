# Rev8 基板データ

既存のRev8製造出力を保存した参照データです。別の版のファイルは混在させていません。

- 基板外形：84 × 73.05 mm、想定板厚1.6 mm。
- 表裏の銅箔・レジスト・シルク、外形、PTH/NPTHドリル、GerberジョブファイルをZIPに収録。
- 元のRev8ソースの確認記録ではERC・DRC・未接続・回路図との不一致は0件。
- 穴はPTH 50か所、NPTH 26か所。基板固定穴4か所とLCD固定穴4か所を含みます。

元プロジェクトの注意事項：Rev8を発注する場合は、対象プロジェクトからGerberとドリルを新規生成して最終確認してください。この公開は既存出力の共有であり、新たな製造承認を示すものではありません。

`SHA256SUMS.txt`で公開ファイルのハッシュを確認できます。
